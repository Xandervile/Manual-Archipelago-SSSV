A Manual Archipelago implementation of Space Station Silicon Valley on the GameBoy.

Features:
- Level Access shuffled as items.
- Trophies shuffled as items and checks.
- Level Completion shuffled as checks.
- Animals shuffled as items.
- Killing Animals shuffled as checks.
- Evo's Body Parts as possible Big Celebration Parade Condition, else need to find the BCP level access.
- Shuffle Power Cells, Energy Cells, Monitors and Tasks per level as checks
- FINALLY FIXED RANDOM STARTING LEVEL!

Future Ideas:
- In level switches (checks and items depending)
- Button usage (A, B and Select)
